Marble Run....

Marble runs have always seemed fun to me ~~mainly because I run really slow and to see someone go fast seems so good~~ because of the sound they make.
It feels so satisfying that you do not want to stop playing with them.

[!1.jpeg]

This the image of the final marble run. Except the standalone path, it also includes two funnels and two Plinko tracks. 
All in all it includes two different tracks for the marbles to run on. First dropped from the funnels they speed up to the center spiral sections and then end up in the base with the Plinko tracks!

[!2.jpeg}
The marble run is intentionally made diagonally so that because of what Newton told us about gravity, if it's true, it will pull the marbles down forcing them to run (how rude) throughout the track!

<hr><br><br>

To build this, you just need to print the stl files and then assemble them as shown in the first image sticking all of them together!
